# stillstamp 고객지원

- 제품·기술 지원: help@akra.kr
- 개인정보 문의: help@akra.kr
- 결제·크레딧 복구: 결제한 Google 계정을 연결한 뒤 상점에서 **구매 복원**을 실행하세요.
  복구가 진행 중일 때 같은 상품을 다시 구매하지 마세요.
- 로컬 엽서 삭제: **내 엽서함**에서 한 장을 삭제하거나, 앱 데이터를 지우거나
  stillstamp를 삭제하여 로컬 기록 전체를 제거할 수 있습니다.
- 광고 개인정보 선택: 표시되는 경우 앱 안의 선택 항목과 기기의 광고 설정을 사용하세요.
- 클라우드 식별정보·지갑 삭제: **내 정보 → 계정 · 크레딧 복구 → 클라우드 계정 삭제**를 선택하세요. 익명
  식별정보와 AKRA가 관리하는 지갑·원장·보상 영수증·생성·임시 결과 기록을 삭제합니다.
  기기에 저장한 엽서는 남습니다. 구매 중복 방지용 거래 기록과 첫 이용 보상 기기
  기록의 별도 보관 범위는 개인정보처리방침을 확인하세요. 중간에 끊기면 앱을 다시 열어 재시도하세요. 삭제가
  끝날 때까지 클라우드 기능은 잠긴 상태를 유지합니다.

문의할 때 앱 버전, 운영체제 버전, 문제가 발생한 화면과 간단한 상황을 알려주세요.
사진, 비밀번호, Firebase 토큰, 비공개 키, 결제 정보 또는 전체 광고 영수증은 보내지
마세요.

앱을 사용할 수 없으면 https://stillstamp.akra.kr/delete-account 에서
이메일 삭제 요청 방법을 확인하세요.

계정 연결로 복구되는 것은 서버 크레딧과 광고 제거 이용권입니다. 엽서함은 기기에만
보관되므로 앱 제거나 데이터 삭제 전에 원하는 기기 위치에 PNG로 저장하세요.
